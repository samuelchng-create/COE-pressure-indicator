# Singapore COE Pressure Index — MVP

A Streamlit prototype that loads official LTA COE bidding data from data.gov.sg, displays Categories A/B/D, and runs a walk-forward structural back-test against a persistence benchmark.

## Run locally
`pip install -r requirements.txt`
`streamlit run coe_pressure_app.py`

## Deploy
Upload `coe_pressure_app.py` and `requirements.txt` to a GitHub repository, then deploy `coe_pressure_app.py` on Streamlit Community Cloud.
